# Expense Log 3.0

Personal money manager for Android, with automatic logging of telebirr and CBE payments.

## Features
- Wallets (cash, bank, mobile money, cards, credit, savings) in any currency
- Expense / income / transfer with calculator keypad, photos, payee, fees
- Categories with subcategories, custom icons and colours
- Records, calendar, statistics (donut + trend charts), search
- Budgets (weekly / monthly / yearly / one-time) with alerts
- Saving goals, debts & loans, recurring transactions, templates
- Multiple books (ledgers), each with its own main currency
- Editable exchange rates and main currency at any time
- Auto-log from telebirr notifications and payment screenshots (on-device OCR)
- Share a receipt screenshot or SMS to the app to log it
- Nightly summary notification and plain-text daily log
- PIN + fingerprint lock, dark mode, hide amounts
- Backup / restore (JSON, any folder incl. Google Drive), auto-backup
- Export to Excel (.xlsx) and CSV
- Home-screen widget

## Build
GitHub Actions builds `ExpenseLog.apk` on every push to `main` (Actions tab → latest run → Artifacts).
